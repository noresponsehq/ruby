# ScreeningCompletedStatus

completed reached every person; partial left some not fully covered (partial_coverage); failed covered nobody.

## Example Usage

```ruby
require "noresponse"

value = ScreeningCompletedStatus::COMPLETED
```

| Name        | Value       |
| ----------- | ----------- |
| `COMPLETED` | completed   |

# Flow

The provider flow the assessment gates. Absent means signup.

## Example Usage

```ruby
require "noresponse"

value = Flow::SIGNUP
```


## Values

| Name             | Value            |
| ---------------- | ---------------- |
| `SIGNUP`         | signup           |
| `LOGIN`          | login            |
| `RECOVERY`       | recovery         |
| `PROFILE_CHANGE` | profile_change   |

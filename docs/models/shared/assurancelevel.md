# AssuranceLevel

Provider or OIDC assurance level, when the customer has mapped one.

## Example Usage

```ruby
require "noresponse"

value = AssuranceLevel::UNKNOWN
```


## Values

| Name      | Value     |
| --------- | --------- |
| `UNKNOWN` | unknown   |
| `LOW`     | low       |
| `MEDIUM`  | medium    |
| `HIGH`    | high      |

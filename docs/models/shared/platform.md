# Platform

Client platform. Closed vocabulary keeps integrations stable.

## Example Usage

```ruby
require "noresponse"

value = Platform::WEB
```


## Values

| Name      | Value     |
| --------- | --------- |
| `WEB`     | web       |
| `IOS`     | ios       |
| `ANDROID` | android   |
| `OTHER`   | other     |
